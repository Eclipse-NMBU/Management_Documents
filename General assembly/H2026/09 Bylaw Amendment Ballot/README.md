# 09 Bylaw Amendment Ballot (retired)

This folder previously held a standalone ballot for the Bylaw Amendment vote (formerly `ECL-H2026-BALLOT-01`).

Only candidate elections use ballots. Bylaw amendments, Agenda items and Case proposals, including the Bylaw Amendment (Case 5), are decided by show of hands, with each Eligible Voter's voter number recorded against their vote. The vote count for Case 5 is now recorded directly in the Meeting Protocol (`26H-ECL-GA-PROT1`), Section 6.

The folder number is kept unused, rather than reused or removed, so the numbering of every other folder in this set does not shift.
