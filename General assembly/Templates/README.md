# Templates

Reusable, semester-agnostic templates for Eclipse NMBU General Assembly documents. Each semester's document set (e.g. `H2026`) copies from these, fills in the placeholders (Document ID, meeting details, and the template's own content fields), and keeps its own filled-in copy under its own numbered folder.

| Template | Purpose |
|---|---|
| `case-template.tex` | The layout every Case Paper follows: C-suite deliberation, Background, Proposal, External information. |
| `case-explanation-template.tex` | A plain-language explanation of a Case, for members: what it is, why it matters, what changes, what does not. |
| `case-defending-template.tex` | An internal preparation document for whoever presents a Case: anticipated objections, key arguments, acceptable Amendments, non-negotiables. Not distributed to the General Assembly. |
| `candidate-consent-template.tex` | General-purpose candidate consent and written-candidature form, for any office or Election Case, not just the C-suite. |
| `ecc-candidature-template.tex` | The Election and Control Committee's own part of a written candidature (the candidate's own part uses `candidate-consent-template.tex`). Applies once the ECC is in place. |
| `ballot-template.tex` | Cut-slip election ballot, N identical slips per A4 page (default 2 x 5 = 10), one page per role. Only candidate elections use ballots; Bylaw Amendments, Agenda items and Case proposals are decided by show of hands with voter numbers recorded. |

Document IDs and abbreviations used across the whole document set are defined in the ID and Abbreviations Reference (see the current semester's folder, e.g. `H2026/19 ID and Abbreviations Reference`).
